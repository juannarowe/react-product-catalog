# React Product Catalog

A single-page application built with React and TypeScript that displays a product catalog with list and detail views. Developed as a level assessment exam for a frontend development course.

## Prerequisites

- Node.js (v18 or higher)

## Installation

```bash
npm install
```

## Run the app

```bash
npm run dev
```

## Run tests

```bash
npm test
```

## Technologies

- React 19
- TypeScript
- React Router v7
- Vite
- Vitest
- React Testing Library
